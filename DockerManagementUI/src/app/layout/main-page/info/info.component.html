Performance Tests UI

This dashboard gives you one place to understand and control the testing environment before running any performance scenarios.

view_in_ar

Docker Resources

Monitor and control your testing infrastructure. The Containers view lets you verify service health and manage their lifecycle, while the Volumes view allows you to inspect and safely remove unused Docker storage volumes.

settings_applications

Environment Management

Prepare the system for testing. Use Environment Start to spin up specific combinations of database and application containers, and Data Generation to automatically populate your configured database with realistic datasets.

speed

Performance Tests

Execute load tests and analyze results. Run Tests allows you to trigger predefined Gatling simulation scenarios, while Previous Runs lets you browse execution history and inspect detailed HTML performance reports seamlessly.
